| Layer            | Technology                                | Purpose                                                                    |
| ---------------- | ----------------------------------------- | -------------------------------------------------------------------------- |
| Glasses          | **Meta Aria Gen 2**                       | RGB camera, microphones/audio, IMU and other available sensor streams      |
| Device SDK       | **Project Aria Gen 2 SDK**                | Connect to glasses, authenticate, configure streaming, receive sensor data |
| Language         | **Python 3**                              | Main application and experiment-control code                               |
| Environment      | **Conda — `MetaAriaGlasses`**             | Isolated Python environment                                                |
| Streaming        | **`aria.stream_receiver`**                | Receives live Aria streams on the Mac                                      |
| Device control   | **`aria.sdk_gen2`**                       | Connect/start/stop/configure the Gen 2 device                              |
| Computer vision  | **NumPy + Pillow/PIL**                    | Image/frame handling and sensor processing                                 |
| Speech-to-text   | **OpenAI transcription API**              | Converts participant speech into text                                      |
| LLM              | **OpenAI model**                          | Answers participant questions / generates study interaction responses      |
| Configuration    | **python-dotenv + `.env`**                | API keys and experiment configuration                                      |
| Data             | **CSV/JSON/NPY/etc. depending on stream** | Participant/session/sensor/event recording                                 |
| Shell automation | **Bash `.sh` scripts**                    | Setup, keyboard mode, wake mode, experiment startup                        |
| Analysis         | **Python + pandas + NumPy + matplotlib**  | Sensor synchronization, feature extraction and statistical/visual analysis |
